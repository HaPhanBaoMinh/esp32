Thời gian

Wi-Fi

Thiết bị sẽ chuyển sang mạng mới; mở lại trang qua http://apphub.local

Firmware (OTA)

Chọn file build/esp32_app_hub.bin. Nếu bản mới lỗi màn hình, thiết bị tự quay về bản cũ.
